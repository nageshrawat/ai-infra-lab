# Day 2 - FastAPI & Backend Basics

## What are APIs?

API stands for Application Programming Interface.

APIs allow applications and systems to communicate with each other.

Example:
- Browser sends request
- Server processes request
- Server returns response

Modern AI systems heavily use APIs for communication.

---

# Difference Between GET and POST

## GET
Used to retrieve data from server.

Examples:
- /cpu
- /memory
- /system

GET requests usually do not send large input data.

---

## POST
Used to send data to server for processing.

Example:
- /analyze

POST requests are commonly used in AI systems where users send prompts, logs, or files to backend services.
