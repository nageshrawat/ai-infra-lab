# Day 5 Learning

## Docker Compose
- Created multi-container application
- Managed FastAPI, PostgreSQL and Redis using Docker Compose
- Learned service discovery and container networking

## PostgreSQL
- Connected FastAPI to PostgreSQL using psycopg2
- Created tables and executed SQL queries
- Performed CRUD operations
- Learned about sequences and primary keys

## Persistent Storage
- Learned difference between container storage and Docker volumes
- Configured PostgreSQL persistent volume
- Verified database survives container recreation

## API Migration
- Migrated all endpoints from in-memory list storage to PostgreSQL
- POST /analyze inserts records into database
- GET endpoints fetch from database
- PUT updates database records
- DELETE removes records from database

## Key Takeaway
A real backend application should store data in a database, not in application memory. Docker volumes ensure database persistence across container restarts and recreations.
